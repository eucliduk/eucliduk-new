## Complete handover, 12 November 2026

The initial 998.5 MB estimate covered the main checkout only. The complete
handover also includes the separately developed DR1 viewers, which initially
added approximately 1.76 GB. The distributable is therefore a separate web
optimised copy: all Deep Zoom image dimensions and zoom levels are retained,
with WebP tiles, optimised page images and H.264 videos. Original source media
remain untouched locally. All-sky map assets and relative viewer links are
included. See the handover's `package-sizes.json` for final measured bytes and
`reference-audit.json` for the complete Deep Zoom pyramid checks.

The folder to publish is `website/` inside the handover. Its `.nojekyll` file
must be retained so underscore-named image tile directories are published.
Do not upload the ZIP, node_modules, .build, .git, or old unused assets. Replace
old website contents rather than accumulating the new package alongside them.
